# Transformer from Scratch

A Python transformer project using NumPy and Apple Metal, with BabyLM data loaded through Hugging Face Datasets.

## Requirements

macOS with Metal support and a Python notebook environment.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

Run the notebook cells in order to load the BabyLM `strict_small` dataset, prepare the tokens, and train the model.
